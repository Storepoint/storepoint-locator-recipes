# Custom filters

Custom filters render their own UI inside the Storepoint search panel and run a synchronous filter function against the visible locations. Build whatever filter UI fits your data — checkboxes, range sliders, date pickers, autocomplete inputs.

| Recipe | What it does |
| --- | --- |
| [date-range](./date-range) | Calendar-style date-range filter on a date custom field |

For the API surface, see [Widget JavaScript API: Add Custom Filter](https://storepoint.co/developers/widget-javascript-api#add-custom-filter).
