# Platform integrations

Patterns for embedding the Storepoint locator inside platforms that need more than the standard embed snippet.

| Platform | What it does |
| --- | --- |
| [shopify](./shopify) | Theme Section with merchant-configurable schema settings, auto-localized per Shopify Market |
| [react](./react) | `useStorepointWidget` hook for React apps |

For platforms not listed here — Webflow, Squarespace, Wix, WordPress, Drupal, Joomla, and others — the [standard embed snippet](../examples/quickstart) works directly. See the [Storepoint platform pages](https://storepoint.co/platforms) for platform-specific install steps.
